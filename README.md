# D's Wrapping Studio — "Wrapped With Love" 🎁✨

A luxury multi-page gifting & hamper website built with pure HTML, CSS, and JavaScript.

## 🌿 Brand Identity & Design System
- **Warm Ivory / Soft Cream (`#F7F1E7`, `#FBF8F1`)**: Primary base canvas
- **Deep Botanical Olive Green (`#31452F`)**: Header navigation, primary buttons, brand accents
- **Muted Sage Green (`#667455`)**: Sub-elements & secondary buttons
- **Champagne Gold (`#B9A16A`)**: Highlights & badge styling

## 📄 Pages Included
1. `index.html` — Homepage with Hero, Featured Hampers, Occasions & Interactive Hamper Builder Modal
2. `about.html` — Story, Philosophy & 5-Step Wrapping Process
3. `collections.html` — Curated catalogue with direct WhatsApp ordering links
4. `custom-hampers.html` — Custom Hamper creation workflow & interactive enquiry form
5. `occasions.html` — Dedicated section for Weddings, Festivals, Trousseau & Corporate Gifting
6. `gallery.html` — Studio portfolio masonry grid showcasing real product photos
7. `contact.html` — Location details, enquiry form & FAQs

## 🚀 Live Preview / Setup
Simply open `index.html` in any browser or serve using a static web server:
```bash
npx http-server . -p 8080
```
